## Danh mục các bài Lab

| Thư mục | Ngoại vi | Chức năng chính | Ghi chú phần cứng |
| :--- | :--- | :--- | :--- |
| **Lab 1** | **GPIO** | Blink LED, Bật/Tắt LED bằng Button | LED (PC13), Nút nhấn (PA0) |
| **Lab 2** | **UART** | Giao tiếp với máy tính (Serial Debug) | Chân PA9 (TX), PA10 (RX) |
| **Lab 3** | **SPI** | Giao tiếp Master - Slave giữa 2 board STM32 | Chân PA4, PA5, PA6, PA7 |
| **Lab 4** | **I2C** | Đọc cảm biến gia tốc ADXL345 | Chân PB6 (SCL), PB7 (SDA) |
| **Lab 5** | **ADC** | Đọc cảm biến nhiệt độ LM35, đọc biến trở | Chân PA0, PA1, PA2 |
| **Lab 6** | **Timer & PWM** | Tạo Delay chính xác, điều chỉnh độ sáng LED | Timer 2 (Delay), Timer 3 (PWM) |
